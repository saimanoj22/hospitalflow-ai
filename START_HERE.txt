HOSPITALFLOW AI — SUBMISSION PACKAGE
====================================

1. TO SEE THE WORKING PROTOTYPE RIGHT NOW:
   Double-click HospitalFlow-AI-Standalone.html
   It works offline in a modern web browser (no install necessary).

   Open the Visual Digital Twin tab (3D is the default). Drag to orbit,
   scroll to zoom, click patient avatars to inspect, toggle 2D/3D,
   and press +30 minutes or Emergency surge to see the model update.

2. TO RUN THE MODULAR REPO VERSION:
   Run in the project folder:
       python3 -m http.server 8000
   Open: http://localhost:8000

3. TO VERIFY THE SIMULATOR:
       node --test tests/*.test.js
